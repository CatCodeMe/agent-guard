# 开发计划

## 0：配置基础（当前增量）

菜单栏入口；手动添加应用或可执行文件；敏感路径预设与自定义规则；记录、询问、阻断的配置；明确标注的模拟事件；本地持久化；规则和存储测试。

验收：原生应用可构建，配置可保存，预览不会读取目标文件，不将模拟事件呈现为真实保护。

## 1：运行时发现与平台可行性验证

当前增量已加入 Codex、Claude、Cursor 的常见安装路径探测，以及 sandbox-runtime 的只读 PATH 探测。识别只生成配置，不启动进程，也不授予权限。

下一步确认 Apple 开发者账号、Endpoint Security entitlement 与 Network Extension 签名部署条件。分别验证真实进程身份、文件打开通知、网络流识别。先记录，再接入授权。验证 CLI、桌面主进程及其辅助进程，避免仅凭进程名匹配。

验收：受控测试程序产生可关联的真实事件；缺失权限时清晰显示未启用；形成部署与权限文档。如果授权不可用，明确限制，不用模拟后端替代验收。

## 2：最小阻断闭环

选择一个文件读取授权场景和一个网络连接场景，完成用户决策、截止时间、超时处理、重试与审计。按测试结果确定默认行为。事件只存必要元数据，不存私钥与请求正文。

验收：使用临时假密钥与本地测试服务，证明允许和拒绝效果；覆盖执行器异常、GUI 退出、子进程及规则变更。验证路径别名与已有连接等绕过面。

## 3：日常可用性

应用识别预设、自定义运行时、低打扰通知、规则管理、登录启动、签名公证与卸载。验证常用 VPN、CLI 与桌面应用组合，并公开支持范围。

## 4：内容检测与其他平台

根据真实需求评估明文代理、Agent hook 或 sandbox-runtime 受控启动适配。内容检测与基础应用防火墙分开标注。Linux、Windows 使用独立平台执行器复用策略约定。
